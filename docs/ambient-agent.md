# Rubicon intelligence presence

`AmbientAgent` is mounted outside page transitions and shares the active agent's conversation through `useHub`.

The orb docks beside market objects, thesis content and memory moments. Pointer and keyboard focus attract it to relevant content, with GSAP easing into a bounded viewport position. Scroll and page content changes update its anchor. After 24 seconds without interaction its idle presence recedes. Reduced-motion preferences remove travel and continuous animation; hidden tabs pause the breathing timeline.

Click the orb or press Command/Control J anywhere to unfold a thought surface from the same spatial origin. Escape and outside clicks dismiss it. Product components can dispatch `rubicon:summon` to open it. `data-intelligence-anchor` marks an explicit docking target; existing worldview objects provide fallback anchors.

Eight states communicate through core density, halo and orbit:
- idle: slow breathing
- listening: brighter focused core
- researching: searching orbit while awaiting output
- noticed: expanded ring for a new contextual thought
- waiting: quiet dashed orbit when a trade requires approval
- assembling: surface bloom animation
- acting: denser core while a response is streaming
- reflecting: desaturated core and flattened orbit after profile updates

Presence notifications retain the existing cooldown and background discovery behavior. The multiline composer sends with Enter and inserts a line break with Shift+Enter. Prompts populate an editable draft; sending and stopping use the existing provider. Trade review stays in Activity. The surface does not execute trades automatically. Context labels describe the current view, not additional evidence or hidden agent work.
